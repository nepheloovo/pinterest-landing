# Pinterest 灵感落地页

按已确认的 A 方案与首屏实现完成的六段式产品落地页。设计方向来自 Planes，内容围绕 Pinterest 的发现、收藏与画板展开。

## 查看与修改

网站完整文件在 `dist/`，无需安装依赖或编译。用静态服务器打开该目录即可，例如在本目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

然后访问 <http://127.0.0.1:4173/>。直接双击 HTML 会影响外部 SVG 符号与浏览器本地存储，建议使用上面的预览方式。

| 文件 | 内容 |
| --- | --- |
| `dist/index.html` | 文案、六个区块、图片、官方链接与语义结构 |
| `dist/tokens.css` | 颜色、字体、字号、间距、圆角、阴影与动效时间 |
| `dist/hero-layout.css` | 已批准首屏的比例和照片位置 |
| `dist/styles.css` | 基础布局与共享按钮、导航样式 |
| `dist/sections.css` | 灵感图墙、筛选与收藏画板 |
| `dist/supporting.css` | App、FAQ 与页脚 |
| `dist/motion.css`、`dist/motion.js` | 入场、滚动、拖拽、暂停与减弱动效 |
| `dist/responsive.css` | 平板、手机和窄屏适配 |
| `dist/app.js` | 本地收藏、筛选、反馈和手机菜单 |
| `dist/light.js` | 首屏蓝色光场 |

根工作区另有同内容的文件镜像，用于设计审阅工具；正式交付以此目录的 `dist/` 为准。修改正式文件后，如要继续使用工作区审阅流程，需同步根目录镜像。`partials/` 是制作时拆分的区块，不是运行时依赖。

## 已完成的体验

1. 首屏：发光 P、两行大标题、两项行动按钮与倾斜照片墙。
2. 灵感发现：All ideas / Home / Style / Food / Travel 五类筛选；图墙自动移动，可拖动、用方向键平移、暂停。
3. 收藏画板：首屏和图墙的 Save 同步；支持移除、清空与刷新保留。
4. App 引导：手机预览、官方 App Store / Google Play 链接。
5. FAQ：五项原生可展开问答。
6. 页脚：大字 Pinterest、注册入口与帮助、隐私等官方链接。

收藏仅存于当前浏览器，不会写入 Pinterest 账号。浏览器不允许本地存储时，本次访问仍能收藏。关闭 JavaScript 后，正文、导航、问答及官方跳转继续可用，增强操作会隐藏。

## 设计系统与素材

原项目没有可复用的网站代码、组件库、字体或动画库。本次新增一套共享变量与按钮、导航、照片卡、筛选器、画板、问答组件，没有引入框架或动画依赖。

主要变量：背景 `#030a12`，前景 `#f8fafc`，次级文字 `#b1b8c4`，Pinterest 红 `#e60023`，蓝光 `#4280f7`；Geist 可变字体；4px 起步的间距尺度；10 / 16 / 24px 与胶囊圆角；1200px 内容容器；44px 最小触控区。全部值集中在 `tokens.css`，完整设计约束见工作区 `DESIGN.md`。

14 张照片为独立生成的示例素材，保留了生成提示、PNG 原件和来源记录；交付使用 WebP。压缩后约 3.01 MB，比原 PNG 合计 35.76 MB 缩小约 91.6%。图片均在本地，不依赖第三方图床。

当前没有未完成的灰色占位图。后续可将照片替换为自有品牌素材，并把画板标题和示例 Pin 文案改成正式内容。若需要真实账号收藏，需另接 Pinterest 支持的授权与服务；当前演示已明确标注其范围。

## 动效参数

| 场景 | 触发、变化与时间 |
| --- | --- |
| 主标题 | 加载后 1600ms 起，两行错开 120ms；1500ms 透明度、位移与模糊入场 |
| 描述与按钮 | 分别延迟 1900 / 2100ms；共享 700ms 入场 |
| 首屏照片 | 加载入场，逐张错开 70ms，900ms 透明度与位移 |
| 蓝色光场 | 5200ms 点亮；9000ms 呼吸周期；指针轻微跟随 |
| 后续区块 | 首次进入视口触发；标题 700ms，正文/图片 900ms；只执行一次 |
| 图墙 | 横向 18px/s、纵向 11px/s；边缘折返；悬停、焦点、拖动或手动暂停时停止 |
| 控件与反馈 | 150–200ms；FAQ 和浮动导航 260ms |
| 共用缓动 | 入场 `cubic-bezier(.16, 1, .3, 1)`；控件 `cubic-bezier(.2, .8, .2, 1)` |

动画只改变 transform、opacity 或 filter。光场只初始化绘制，持续变化交给外层的上述属性。系统开启“减少动态效果”时，入场静态显示、图墙默认暂停；页面信息和操作仍可用。

## 验证与参考差异

已检查 1440、1200、768、390、360px 宽度：没有页面横向滚动、图片加载失败或小于 44px 的可见操作目标。验证了收藏刷新同步、筛选、删除、键盘平移、手机菜单与 Escape 焦点恢复、无脚本内容以及存储受限回退；35 个图片实例均使用 WebP。

参考研究包含 Planes 的真实 CSS / JS、三种宽度截图，以及提供的视频逐帧分析。最终保留其深色、冷蓝光、紧凑字距、图片密度与慢速运动；替换了品牌、文案和素材。照片细节按你的明确许可使用已确认素材；首屏以你已批准的实际效果为准。

图墙是有限范围的自动折返和手动平移，没有实现 Planes 的无限平面。光场为适配当前 P 形标记重新制作，光线形状不与参考逐像素相同。后续区块是沿同一系统展开的原创 Pinterest 内容。
